# House Price Dataset for Multiple Linear Regression

This dataset contains 50 rows and 4 columns:
- `size_sqft` (square feet)
- `bedrooms` (number of bedrooms)
- `age_years` (age of house in years)
- `price_usd` (house price in USD)

Used for a multiple linear regression assignment in Google Colab.
